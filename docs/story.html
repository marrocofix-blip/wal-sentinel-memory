WAL Sentinel Memory

Research predictions are easy to make and difficult to audit. WAL Sentinel Memory explores how verifiable memory and Sui network context can make market predictions more accountable: what did we observe, what did we predict, when did we predict it, and what happened afterward?

Core idea

Attach a prediction to a timestamped market observation and its data provenance. Record the outcome only after a matching candle closes, so pending predictions are never counted as wins.

Architecture

The interactive market terminal reads publicly available WAL/USDT spot candles on 5m, 15m, 1h and 4h intervals, with Binance Spot as the preferred source and Gate Spot as a fallback. It shows actual closed-candle OHLC and volume with EMA 9/30/200, RSI 14, MACD 12/26/9, a candlestick and line display, and contextual session metrics. The research journal records local 15-minute predictions, offers JSON export, and scores only matching observed target closes. Tatum supplies read-only Sui Mainnet checkpoint context. Official Walrus Memory MCP has returned an authorized test record with a complete exact-text match.

What has actually been verified?

Tatum gRPC successfully returned historical checkpoint 341126670 on 2026-11-03T07:19:38.100Z in an earlier local PowerShell run. A later Codex process lacked the API key; its separate check was blocked. The official Walrus MCP recall returned the authorized record in wal-sentinel-memory-v1; the record body matched exactly. Neither a simultaneous combined live run nor a Walrus blob receipt has been independently verified.

Transparency: the public site shows historical and recorded evidence, not simulated blockchain success. The journal is browser-local and not yet memory-backed across sessions. There have not been ten verified Mainnet memory records for this project.

Demo flow

  1. Open the dashboard and inspect the recorded Tatum and Walrus evidence.
  2. Explore closed WAL/USDT candles across 5m, 15m, 1h and 4h, switch candle/line view, and inspect EMA, RSI, MACD, and volume indicators.
  3. Record a direction and a future evaluation time. The prediction begins PENDING.
  4. On a later visit, compare with the matching completed candle if it remains available from the provider.
  5. Export the browser-local journal as JSON. Review the evidence and source code rather than trusting a made-up accuracy claim.

Implementation status

The public market API is a read-only spot-candle adapter with provider failover; it has no trading capabilities. The interactive dashboard remains a research prototype, not a trading exchange, price oracle, or backed prediction service. Its journal remains browser-local and outcome evaluation depends on the corresponding market candle being in available history.

Roadmap and honest gaps

The next engineering milestone is a securely authorized write-and-recall trail for at least ten real Mainnet records, then cross-session outcome evaluation, an independently verifiable receipt, and a complete live end-to-end demo. No extra Mainnet writes or paid transactions have been authorized in this session.
